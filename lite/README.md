# Lite version

Минимальная версия: получает email-уведомление о заказе через Yandex Email Trigger, парсит письмо и отправляет сообщение в Telegram.

Не использует YDB, YMQ, webhook и кнопку принятия.

├─ index.js
└─ package.json
